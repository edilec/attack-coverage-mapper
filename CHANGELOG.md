# Changelog

## 0.1.0 — 2026-10-13

Initial offline normalized-subset mapper with strict analyst activity/note declarations, separate detection outcomes and source ordinals, the catalog report/exit contract, CSV and version-declared Navigator 4.4 exports. Includes inclusive bounds, cooperative injected deadline, deterministic ordering, private source roles, and guarded exclusive creation of new artifacts.

Raw STIX and automatic mapping are unsupported. Provenance and note availability remain supplied declarations. Incomplete datasets omit Navigator output; incomplete activity runs are unscored. Multi-file writes are not atomic. No remote code, package, or website publication is implied by this local release record. Stable rule IDs are documented; renames require a breaking-change entry.
